SVWF Solver API (Python)
========================

The spherical expansion module provides tools for solving scattering problems using Spherical Vector Wave Functions (SVWF) and Generalized Sheet Transition Conditions (GSTC). This solver is primarily used for benchmarking and validating the SIE implementation.
