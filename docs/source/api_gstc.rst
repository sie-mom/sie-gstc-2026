GSTC Parameter Extraction API (Python)
======================================

The GSTC utilities form equivalent sheet currents from prescribed tangential
fields and extract reciprocal lossless omega-biisotropic parameters. Vector
arrays use component-first local tangential ordering :math:`(u,v)`.
